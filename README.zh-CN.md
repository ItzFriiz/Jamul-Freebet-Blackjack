# Free Bet Blackjack

Jamul Casino 的 Free Bet Blackjack，跑在终端里。赌场替你出大部分加倍和分牌的钱。
作为交换，庄家 22 点和所有没爆的玩家平局。

规则是在牌桌上记的，不是从通用说明里抄的。[完整规则在这里。](docs/RULES.zh-CN.md)

## 跑起来

需要 Python 3.11 以上和 [rich](https://github.com/Textualize/rich)。

```bash
pip install rich
python play.py
```

| 命令 | 作用 |
|---|---|
| `python play.py` | 正常开一靴牌 |
| `python play.py --seed 7` | 固定洗牌结果，可以复现同一局 |
| `python play.py --list-scenarios` | 列出预排好的牌堆 |

窗口开到 110 列。每个投注格占一列，窄于 104 列左右 rich 会开始截断标签。牌那一列有保护，
不会被挤掉。

## 开局设置

问三件事：桌面最低注（$25 或 $50）、多久换一次庄（默认 10 分钟，填 0 不换）、五个座位各坐谁。

每个座位填一个名字，或者直接回车留空。输 `?` 列出所有电脑角色和简介。输 `-` 退回上一个座位。
最后有一步确认，那时候任何座位都还能改。

你是空手上桌的。用 `i 500` 买筹码。

## 下注

敲下金额，注就放到台面上。筹码从架子上扣掉，牌桌上马上显示。放不上去的注当场被拒绝，
那一格保持原来的金额。不存在等待确认的中间状态。

| 键 | 作用 |
|---|---|
| `b 50` | 底注 |
| `p 5` | PUSH 22 |
| `u 5` | BUSTER |
| `k 5` `kp 5` `ku 5` | 替庄家在这三个格子上下注。`0` 撤回 |
| `b 0` | 撤掉底注。边注跟着一起撤 |
| `i 200` | 补买筹码 |
| `x 25 2 5` | 换筹码，2 个 $25 换成 $5 |
| `t 5` | 直接给庄家小费 |
| `o` | 这一局不玩 |
| `q` | 退出 |
| 回车 | 下好了 |

赢了或平局的注留在格子上，下一局重复只要一次回车。输掉的注被收走，要重新下。

所有人下完之后，牌桌会把整桌的注摆出来让你再看一眼。在那一步输 `go 1` 回到 1 号座位改注。

## 打牌

| 键 | 作用 |
|---|---|
| `h` | 要牌 |
| `s` | 停牌 |
| `d` | 加倍。青色的 `Double (FREE)` 表示赌场出钱 |
| `p` | 分牌。青色的 `Split (FREE)` 表示赌场出钱 |

只显示合法的选项。钱不够的动作直接不出现。

9、10、11 免费加倍。除了两张 10 点牌以外的对子都免费分牌。
[细节见规则。](docs/RULES.zh-CN.md#你能对手牌做什么)

## 看懂桌面

| 看到的 | 意思 |
|---|---|
| 座位顺序 | 真实牌桌上 1 号在最右。发牌 1 到 5 |
| `bot` | 这个座位是电脑角色。真人不带标记。真人可以取和角色一样的名字，光看名字分不出来 |
| `??` | 你没看到的牌 |
| 点数列的 `?` | 这手还有牌扣着，谁也算不出总点数 |
| `base` `free` | 你的钱，和赌场出的 free bet |
| `P22` `BST` | 你自己的两个边注 |
| `dlr` 那三列 | 你替庄家下的三个格子 |
| 格子里的 `-` | 这里没下注。空格子永远显示横杠 |
| `#2` | 分牌之后这个座位的第二手。边注属于座位，只写在第一行 |

你起手那两张对别人是暗的，别人的对你也是暗的。要牌补进来的牌是明的。爆牌、blackjack、
加倍、分牌都会把整手翻开。结算时庄家从 5 号翻到 1 号，把剩下的翻开。
[完整规则。](docs/RULES.zh-CN.md#你能看到哪些牌)

牌桌下面是牌堆面板和两个边注的赔付表。牌堆面板三个数加起来永远是 104。它的 `unseen`
包含台面上所有扣着的牌，所以那才是算牌该用的分母。

## 多人同桌

五个座位，每个都可以是真人或电脑角色。几个真人可以共用一个终端，轮到谁谁操作。

| 键 | 作用 |
|---|---|
| `add Ernie` | 叫人上桌，角色和真人都用这个。`add ?` 列出所有角色 |
| `remove 3` | 请 3 号离桌。他还没发牌的注全额退回 |
| `move 5` | 换座位，连人带筹码一起搬 |
| `join 2` | 在旁边的座位上再打一手 |
| `go 2` | 在自己的几个格子之间切换改注 |
| `drop 2` | 放弃多开的某一格 |
| `stand` | 离座，站在旁边看 |
| `ask 2` | 请 2 号换个座位，好空出你旁边的位子 |
| `nice 2` `rude 2` | 夸人或骂人 |

电脑角色有自己的本金、下注习惯和脾气。骂过的人之后再请他让座就难了。输光了会离桌。

他们的一切都写在 TOML 里，改这些不用碰 Python：

| 文件 | 内容 |
|---|---|
| [`data/players.toml`](data/players.toml) | 角色 |
| [`data/dealers.toml`](data/dealers.toml) | 庄家 |
| [`data/chatter.toml`](data/chatter.toml) | 庄家说的话 |
| [`data/table_talk.toml`](data/table_talk.toml) | 玩家之间说的话 |

多开的格子要占相邻座位，共用同一叠筹码。站起来会带走全部格子。换座位只保留搬过去的那一格。

随时可以坐空位，但这一靴打完之前不能下注。这条规则挡住的是等牌面好了再插进来的算牌者。

## 预排牌堆

有些情况靠等是等不到的。准备了六副叠好的牌。

```bash
python play.py --list-scenarios
python play.py --scenario resplit-chain
```

| 牌堆 | 演示什么 | 该按 |
|---|---|---|
| `split-double` | 免费分牌，两手都免费加倍 | `p d d` |
| `resplit-chain` | 分成 4 手，其中 3 手免费加倍 | `p p d p d s d` |
| `resplit-aces` | 分 A 之后又拿到 A，再分一次 | `p p` |
| `dealer-22` | 两手免费加倍，庄家 22 点全部平局 | `p d d` |
| `ten-split` | 自费分 10 和 K，看 A+10 为什么只算 21 | `p s s` |
| `buster-jackpot` | 玩家 blackjack 撞上庄家 7 张爆牌 | 不用按 |

画面顶上有黄框写明这副牌演示什么、该按哪几个键。脚本发完之后牌靴恢复随机发牌。

有两件事和平时不一样。只坐一个人，因为脚本是按单人的发牌顺序码的。筹码和注都替你摆好，
因为赔付金额是按固定注额手算出来的。

## 目录结构

| 目录 | 内容 |
|---|---|
| `engine/` | 牌靴、手牌、筹码、结算、牌桌状态 |
| `tui/` | 终端界面 |
| `data/` | 庄家、角色、对话 |
| `docs/` | 规则 |
| `play.py` | 入口 |

`engine/` 完全不知道界面的存在。

一局牌是一个显式的状态机。它把决策节点（有人要选）和机会节点（要从牌靴发一张牌）分开。
牌靴是一张计数表，不是洗好的列表。这两个选择都是为了让求解器能直接问它
「下一张是 10 点牌的概率是多少」并求期望。

庄家的暗牌不到需要的时候不抽，所以没见过的牌是真的没见过。

金额全程用整数「分」存储。
