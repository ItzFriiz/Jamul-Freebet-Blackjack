# Free Bet Blackjack，Jamul Casino 的规则

21 点加两条方向相反的改动。赌场替你出大部分加倍和分牌的钱。作为交换，庄家 22 点不算爆牌，
而是和所有没爆的玩家平局。

下面写的都是在这些规则来源的那张牌桌上记下来的。凡是赌场有选择余地的地方，
写下来的就是这家的选法。

[English](RULES.md) · [怎么玩这个程序](../README.zh-CN.md)

## 牌与牌靴

两副标准扑克，104 张，无鬼牌。

每次洗牌之后烧掉第一张。它扣着进弃牌堆，没人看得到。

牌靴后段插一张黄卡。黄卡后面剩多少张牌服从正态分布，均值 26，标准差 3，截断在 16 到 36 之间。
发牌途中翻出黄卡时，庄家把它取出放到一边，用下一张继续发。黄卡出现的那一轮是这靴的最后一轮。

万一一轮打到一半牌靴空了，就把弃牌堆洗回来接着发，不含此刻还在台面上的牌。黄卡插得够深，
实际上不会发生。牌靴是按不会卡死来做的。

同一靴牌中途换庄家要多烧一张。刚洗完就换庄不用多烧，因为洗牌已经烧过了。

## 牌桌

五个座位，编号 1 到 5。真实牌桌上 1 号在最右，所以发牌和行动都是 1 到 5，从右往左。
空座位跳过。

庄家大约每十分钟换一班，只在两手之间换。到点时有一局正在进行的话，先打完这一局。

## 下注

| 格子 | 范围 |
|---|---|
| 底注 | 最低 $25，赌场繁忙时 $50。最高 $1,000 |
| PUSH 22 | $0 到 $1,000 |
| BUSTER | $0 到 $1,000 |

边注需要有底注撑着。

赢了或平局的注留在格子上，下一局接着跑。输掉的注被收走，要重新下。两个边注各按自己的输赢算，
所以手牌输了但 PUSH 22 中了的那一局，底注格空了，PUSH 22 继续跑。

## 筹码和取整

筹码面额是 $1、$2.5、$5、$25、$100、$500、$1,000。

$2.5 可以用来下底注，所以底注可以带五角。$27.5 是合法的底注。这些筹码能凑出所有五角的倍数，
只有 $0.5 和 $1.5 凑不出来。

凑不出的零头一律朝对赌场有利的方向取。

| 方向 | 怎么取 |
|---|---|
| 你付钱（保险、自费加倍） | 向上 |
| 赌场付你（blackjack、边注赔率） | 向下 |

$27.5 的底注拿到 blackjack，1.5 倍是 $41.25，实际给你 $41.00。这个底注的保险是 $13.75，
你实际付 $14.00。

**买入。** 你空手上桌，坐下之后随时可以买筹码。庄家给的是 $25 和 $5，方便你直接下注。
先给 20 个 $5，剩下的换成 $25，零头用 $5 / $2.5 / $1 补。买入 $500 拿到 16 个 $25 加 20 个 $5。

任何时候都能找庄家换面额，一手牌打到一半也行。

**赔钱。** 庄家用你下注时的面额赔，小面额攒多了会并成大的。5 个 $5 并成 1 个 $25，
2 个 $2.5 并成 1 个 $5。

## 给庄家小费

两种方式，性质不同。

**直接给筹码。** 钱就没了，不参与之后的结算。

**替庄家下注。** 你自己掏钱押在某个格子上算庄家的。前提是你自己在同一个格子上得有注。
你没下 PUSH 22 就不能替庄家下 PUSH 22。底注本来就是必下的。这种注不受桌面最低注限制，
只下 $1 也行。

| 结果 | 怎么算 |
|---|---|
| 赢 | 归庄家，本金带赢的钱一起。你一分拿不到 |
| 输 | 和别的注一样输掉 |
| 平 | 留在台面上，下一局继续替庄家跑。下一局开始前随时可以拿回来 |

赌场替你出加倍或分牌的钱时，庄家那份也跟着，同样由赌场出。你自己掏钱分牌的时候，
新格子上庄家那份也要你自己再掏。赌场只在自己出钱的格子上放 free bet。自费加倍则庄家那份不跟。

## 发牌

每个玩家两张暗牌。庄家一张明牌，一张暗牌。

| 庄家明牌 | 怎么走 |
|---|---|
| A | 先向所有人提供保险，然后 peek 暗牌 |
| 10、J、Q、K | 直接 peek，不提供保险 |
| 其他点数 | 不 peek，不提供保险 |

peek 到 blackjack 就立即结算，玩家不再行动。

## 你能看到哪些牌

这是规则，不是界面的取舍。它精确决定了一个算牌的人有权看到过哪些牌。

你起手那两张是暗的。你可以看自己的，别人看不到。

要牌补进来的牌是明的，全桌都看得见。你起手那两张仍然扣着。

有四种情况会把整手牌翻过来，翻了就不再盖回去。

| 触发 | 为什么 |
|---|---|
| 爆牌 | 牌直接丢出来 |
| blackjack | 当场亮出来好结算，不管这个座位排在你前面还是后面 |
| 要 double | 要加注就得亮牌 |
| 要 split | 同上，分出来的两手也都是明的 |

hit 到 21 点不是 blackjack，不摊牌。停牌的手一直扣着，直到结算。结算时庄家把还没看到的牌
翻开，从 5 号翻到 1 号。

算牌的口径是，扣在台面上的牌算作没看见，和庄家暗牌一样。它是离开牌靴了，但没人被亮过。

## 玩家动作

要牌和停牌照常。没有投降。

### 加倍

起手两张点数为 9、10、11 时免费。赌场在你的注旁边放一个等额 free bet，只再发一张牌。

判定时 A 按 1 或 11 记都行。A+8 当 9，A+9 当 10，分牌之后的 A+10 当 11。

其他点数可以自费加倍，同样只发一张。金额必须等于底注，不支持加倍时少下。

### 分牌

任意对子都可以免费分牌，只有 10 点对子例外。赌场在新格子上放一个等额 free bet。

拆掉 20 点是你自己的主意，所以 10/J/Q/K 的对子是自费分牌。你要自己再拿出一份等额底注。

对子按点数算。10+K、J+Q 以及任意两张 10 点牌都算对子，都可以分。这种分牌要花你的钱。

| 规则 | 细节 |
|---|---|
| 分牌次数 | 没有上限。分出来的手又是对子可以接着分 |
| 分出来的手加倍 | 是 9、10、11 的话仍然免费 |
| 分 A | 每手只补一张。补到的又是 A 可以继续分 |
| 分牌后的 A+10 | 只算 21 点，不算 blackjack。10 点牌分牌后配到 A 也一样 |

## Blackjack 与保险

起手两张是 A 加一张 10 点牌，赔 1.5 倍。hit 到 21 不算。

| 庄家明牌 | 你的 blackjack 怎么算 |
|---|---|
| 不是 A 也不是 10 点 | 立即结算，赔 1.5 倍。庄家不可能有 |
| 10 点 | 庄家先 peek。双方都是 blackjack 就平局，否则赔你 1.5 倍 |
| A | peek 之前先提供保险 |

保险金额必须恰好是底注的一半，不能多也不能少，赔率 2:1。一半凑不出筹码时向上取，
$27.5 的底注要付 $14.00 的保险。

没有单独的 even money 按钮。even money 就是给 blackjack 买保险，两条路结果一样。

| 庄家有 blackjack | 你这手 | 保险 | 净额 |
|---|---|---|---|
| 有 | 平局 | 赔 2:1 | 净赢 1 倍底注 |
| 没有 | 赔 1.5 倍 | 亏 0.5 倍 | 净赢 1 倍底注 |

拿着 blackjack 面对 A 不买保险的话，庄家有 BJ 就平局，没有就赔你 1.5 倍。

## 庄家怎么打

庄家软 17 必须要牌，硬 17 及以上停牌。

暗牌一定要翻开。翻开之后，庄家只在台面上还有东西等着他的时候继续补牌。

| 还在等 | 为什么 |
|---|---|
| 有任何一手玩家的牌没爆 | 要比点数，还要看会不会 22 平局 |
| 台面上有 PUSH 22 或 BUSTER | 这两个只看庄家的最终结果 |

每一手要么爆了要么是 blackjack，而且一个边注都没有，那就没什么好等的了。庄家翻开暗牌，
不再补牌，直接收拾牌桌。

### 庄家 22 点

庄家最终恰好 22 点时，所有没爆的玩家一律平局，包括 hit 到 21 点的那手。free bet 标记全部收回。
你自费加倍投进去的钱全额退回。

超过 22 点就是正常爆牌，所有没爆的玩家赢。

你自己爆牌是立即输的。庄家 22 救不了你。底注和自费加倍的钱都输掉，free bet 标记收走。

## 钱是怎么走的

`B` 是你的底注。

| 情况 | 赢 | 输 | 平 |
|---|---|---|---|
| 普通一手 | +`B` | −`B` | 0 |
| 免费加倍（`B` 你的，`B` 赌场的） | +`2B` | 只输 `B` | 退回 `B`，标记收走 |
| 免费分牌（新格子是赌场的 `B`） | +`B` | 不输钱 | 0 |
| 免费分牌之后又免费加倍（`2B` 全是赌场的） | +`2B` | 不输钱 | 0 |
| 自费分牌，10 点对子（新格子是你的 `B`） | +`B` | −`B` | 退回 `B` |
| Blackjack | +`1.5B` | | |
| 保险 | +2 倍保费 | −保费 | |

免费加倍让你的赢翻倍，输不翻倍。这个游戏的全部意义就在这里。

被你自费分掉的那个格子上如果有替庄家的注 `T`，新格子上也要有一份 `T`，同样是你自己掏。
这两份 `T` 赢了都归庄家，输了就没掉。

## 边注：PUSH 22

庄家最终点数恰好 22 时中奖，否则输。和你自己的手牌完全无关，你自己爆牌了也照赔。

赔率取决于组成庄家这 22 点的所有牌。

| 庄家的牌 | 赔率 |
|---|---|
| 不同色 | 8:1 |
| 全部同色，全红或全黑 | 20:1 |
| 全部同花 | 50:1 |

庄家 blackjack 时牌停在 21 点，所以 PUSH 22 输。

## 边注：BUSTER

庄家最终点数超过 21，含 22，中奖，否则输。同样和你自己的手牌完全无关。

赔率取决于庄家爆牌时手上有几张牌。

| 庄家牌数 | 赔率 | 额外奖金 |
|---|---|---|
| 3 到 4 张 | 2:1 | |
| 5 张 | 4:1 | |
| 6 张 | 15:1 | |
| 7 张 | 50:1 | $1,000 |
| 8 张及以上 | 250:1 | $8,000 |

额外奖金要同时满足两个条件。你本人这手是 blackjack，桌上别人有不算。你下了 BUSTER 边注，
金额大于 0。

奖金是固定金额，和你边注下多少无关。

庄家 blackjack 时牌停在 21 点，所以 BUSTER 输。

## 上桌和离桌

随时可以走，但要先打完你有注的这一局。走完可以留在旁边看。

随时可以坐任何一个空位，但这一靴打完之前不能下注。位子先归你。这才是不许中途入局的实际含义。
它挡住的是等牌面好了再插进来的算牌者，同时也让中途退出变成一个有代价的决定。

已经在座的人补买筹码和换座位都不受上面那条限制。

占座不玩是允许的，坐着不下注跳过几局，座位仍然算你的。

站在旁边看是一个正经的位置。筹码跟着你走，有没有座位都能一直看下去。

一个人可以打多手，占相邻的座位。每一手的注额要求和单手一样。所有格子共用同一叠筹码，
不需要事先往哪个格子里拨钱。站起来会带走全部格子。换座位只保留搬过去的那一格。

## 可配置参数

全部在 [`engine/config.py`](../engine/config.py) 里，是个冻结的 dataclass。
改规则是新建一个 `Rules`，不是就地改。

| 参数 | 默认值 | 含义 |
|---|---|---|
| `num_decks` | 2 | 共 104 张 |
| `burn_cards_per_shuffle` | 1 | 每次洗牌烧几张 |
| `cut_remaining_mean` | 26 | 黄卡后剩余牌数 |
| `cut_remaining_sd` | 3 | 标准差 |
| `cut_remaining_min` | 16 | 截断下界 |
| `cut_remaining_max` | 36 | 截断上界 |
| `num_seats` | 1 | 多人桌是 5 |
| `min_bet` | $25 | 开局设置时选 |
| `max_bet` | $1,000 | |
| `max_side_bet` | $1,000 | 每个边注 |
| `free_double_totals` | {9, 10, 11} | A 按 1 或 11 记都算 |
| `ten_ranks_are_pairs` | true | 10/J/Q/K 互为对子 |
| `ten_pair_split_is_free` | false | 10 点对子是自费分牌 |
| `max_splits` | 无 | 不限次数 |
| `dealer_hits_soft_17` | true | |
| `dealer_push_total` | 22 | 招牌规则 |
| `dealer_shift_minutes` | 10 | 设为 0 就不换庄 |

金额全程用整数「分」存储。1.5 倍赔付、2:1 保险、$2.5 筹码放在一起，用浮点数会累积误差，
几十万手下来账就对不上了。
